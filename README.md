#### Ecoverse

### Engineering better futures through climate science, sustainable technology, and accessible web design.

[View the live website](https://aschiffmaier.github.io/Ecoverse/)

Ecoverse is an interactive event website centered on sustainability, climate technology, geospatial innovation, and responsible space exploration. It was originally developed as my honors capstone for CodePath’s WEB101: Intro to Web Development course during Spring 2025.

The project progressed from an initial HTML wireframe into a responsive, interactive website over four development milestones. It combines environmental communication with accessible frontend design, offering visitors an imagined event experience featuring educational content, technology showcases, and an interactive RSVP system.

## Project Overview

* **Course:** CodePath WEB101: Intro to Web Development
* **Project Type:** Honors Capstone
* **Development Period:** February–May 2025
* **Role:** Web Developer and UI/UX Designer
* **Technologies:** HTML5, CSS3, JavaScript, Flexbox
* **Original Environment:** Visual Studio Code for Education
* **Current Deployment:** GitHub Pages

## Features

* Semantic HTML5 structure
* Responsive layouts created with CSS and Flexbox
* Light and dark interface modes
* Reduced-motion accessibility control
* Scroll-triggered animations
* Interactive event schedule
* Embedded educational media and external resources
* Dynamic RSVP form
* Real-time input and email validation
* Automatically updating RSVP counter
* Personalized confirmation modal
* Optional modal animation controls
* Early modal dismissal
* Custom favicon and navigation system

## Accessibility

Accessibility was incorporated as a functional part of the experience rather than treated solely as a visual consideration.

Ecoverse includes:

* A **Reduce Motion** control for visitors who prefer limited animation
* A **Dark Mode** option for an alternate viewing experience
* Semantic page structure supporting clearer content organization
* Form labels and validation feedback
* Navigation links that help visitors move between major sections

## Event Themes

The fictional Ecoverse event explores the relationship between environmental responsibility and emerging technology through topics such as:

* Climate and Earth monitoring
* Smart energy grids
* Water-conservation technology
* Sustainable urban design
* Bioplastics and greenhouse innovation
* Geographic information systems and environmental resilience
* Aerospace engineering and orbital-debris mitigation

## Development Process

Ecoverse was completed through four progressive development milestones:

1. **Structure:** Built the initial page architecture with semantic HTML.
2. **Visual Design:** Developed the environmental theme, responsive layout, and interface styling with CSS and Flexbox.
3. **Interaction:** Added JavaScript-based RSVP behavior, validation, counters, modals, and theme controls.
4. **Accessibility and Refinement:** Implemented reduced-motion behavior, animation controls, navigation improvements, and final interface details.

The project began with a broad content and visual concept focused on climate initiatives, smart cities, citizen science, and sustainable technology. Its scope was later refined into a fictional interdisciplinary event connecting Earth systems, engineering, and space sustainability.

## Running the Project Locally

Ecoverse is a static frontend website and does not require a package manager or build process.

1. Download or clone this repository:

```bash
git clone https://github.com/aschiffmaier/Ecoverse.git
```

2. Open the project directory:

```bash
cd Ecoverse
```

3. Open `index.html` in a web browser.

For the best local development experience, open the repository in Visual Studio Code and use a local server extension.
